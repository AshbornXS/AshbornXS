### 🚀 Projetos em Destaque

#### 🚍 [BusStop - Mobilidade Urbana Inteligente](https://github.com/AshbornXS/busstop)
> *Full Stack & IoT*

Sistema completo para gestão de transporte público. Integra rastreamento veicular em tempo real via hardware IoT customizado com uma plataforma web para usuários e administradores.
* **Tech:** Node.js, Express, MongoDB, JavaScript (ES6+), Google Maps API, PWA.
* **Destaque:** Simulação de recarga via PIX e telemetria veicular com ESP32.

#### 📱 [RAE - Relação Aluno x Escola](https://github.com/AshbornXS/RAE)
> *Mobile Android Nativo*

Aplicativo Android desenvolvido para facilitar a comunicação entre instituição de ensino e alunos. Permite gestão de perfil, visualização de avisos e integração com serviços acadêmicos.
* **Tech:** Kotlin, Firebase (Auth, Realtime Database, Storage), Android XML/ViewBinding.
* **Destaque:** Autenticação segura, feed de notícias dinâmico e gestão de perfil com upload de fotos na nuvem.

#### 📚 [ReadVerse - Biblioteca Digital](https://github.com/AshbornXS/Akashic)
> *Web Application*

Plataforma web para catálogo e gestão de livros (Loja/Biblioteca). Conta com sistema de busca avançada, filtros, favoritos e painel administrativo para CRUD de obras.
* **Tech:** HTML5, CSS3, JavaScript (Vanilla), Integração REST API.
* **Destaque:** Interface responsiva, sistema de avaliações (estrelas), filtros dinâmicos e painel admin seguro.
